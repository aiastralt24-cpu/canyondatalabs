# Canyon Data Labs Website

Premium static website and brand platform for Canyon Data Labs.

## Run Locally

```bash
python3 -m http.server 7500
```

Then open:

```text
http://127.0.0.1:7500
```

## Check

```bash
npm run build
```

## Key Files

- `index.html` - main website
- `styles.css` - visual system and responsive layout
- `script.js` - motion, menu, form helpers, canvas effects
- `docs/canyon-brand-book.md` - brand guidelines
- `docs/canyon-website-prd.md` - website PRD
- `assets/images/` - logo and visual assets
